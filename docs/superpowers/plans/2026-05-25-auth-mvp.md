# Auth MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the backend authentication foundation for OAuth login, DealMoa JWT access tokens, refresh token rotation, and authenticated user lookup.

**Architecture:** Keep auth as its own FastAPI feature module. OAuth provider HTTP calls live behind a client protocol so tests can use fake profiles; PostgreSQL stores users, OAuth account links, and hashed refresh tokens; routers raise project domain exceptions instead of FastAPI business errors.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, Pydantic, PyJWT, httpx, pytest, mypy, ruff.
